STREAMBOX-X V18 - PROJET GITHUB PRÊT À COMPILER

1. Remplacer le contenu du dépôt GitHub ghostbuilderDev/StreamBox-X par le contenu de cette archive.
2. La GitHub Action "Build Android APK" se lance automatiquement.
3. Quand le run est vert, télécharger l'APK dans Releases > StreamBox-X APK,
   ou dans Actions > run réussi > Artifacts > StreamBox-X-apk.
4. Sur Android, ouvrir le fichier APK et autoriser l'installation depuis cette source.

Ne pas importer cette archive dans la zone "Projet ZIP complet" de HTMLtoAPK.
